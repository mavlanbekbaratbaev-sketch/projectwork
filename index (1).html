Правила доступа (ACL)

  • Гости (VLAN 50) — только в интернет, без доступа в другие VLAN.
  • Пользователи (VLAN 40) → сервер умного дома по портам 443 и 1883.
  • IoT-устройства (VLAN 20) не инициируют соединения в VLAN 40.
  • Камеры (VLAN 30) отправляют поток только на сервер.
  • VPN-клиенты получают доступ только к серверу (порт 443).

Расчёт подсети

Маска /24 = 255.255.255.0, 254 адреса. Для IoT-VLAN планируется до 60 устройств с запасом ×4 на расширение.

Оборудование и протоколы

Что используем и зачем

Оборудование

  • Маршрутизатор Cisco 2911 — выход в интернет, NAT, DHCP, межVLAN-маршрутизация (router-on-a-stick).
  • Коммутатор Cisco 2960 — доступ, VLAN, порты в режиме access.
  • Точка доступа Wi-Fi — смартфоны, датчики и гостевая сеть.
  • Сервер умного дома — шлюз, MQTT-брокер, правила автоматизации.
  • Умные устройства — освещение, розетки, замок, датчики, камеры.

Протоколы

  • MQTT — лёгкий обмен командами и телеметрией, порт 1883.
  • HTTP/HTTPS — веб-интерфейс и приложение, порт 443.
  • RTSP — видеопоток камер, порт 554.
  • DHCP, DNS, NTP — адреса, имена, время.
  • 802.1Q — разметка VLAN на магистральных портах.
  • WPA2/WPA3 — защита Wi-Fi.

Дополнительные компоненты

  • Zigbee-хаб — подключает энергоэкономные датчики, которые не работают по Wi-Fi.
  • PoE-коммутатор — питание камер и точек доступа по кабелю.
  • ИБП — работа охраны и связи без света.
  • Резервный канал 4G — интернет при сбое провайдера.
  • NAS — хранение видеозаписей.
  • Локальный сервер (например, Home Assistant) — дом работает без интернета.
  • VPN — безопасный удалённый доступ.

Правила автоматизации

  • Протечка → клапан воды перекрывается.
  • Дым или газ → включается сирена.
  • Окно открыто при включённой охране → уведомление.
  • CO₂ выше нормы → включается вентиляция.
  • Сухая почва → запускается полив.
  • Движение в прихожей → включается свет.

Безопасность

  • Изоляция IoT-сегментов от пользовательских устройств.
  • Смена паролей по умолчанию, отключение неиспользуемых портов (shutdown).
  • Port-security на коммутаторе, SSH вместо Telnet.
  • Резервное питание (ИБП) для роутера и сервера.
